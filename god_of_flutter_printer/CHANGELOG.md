## 0.1.0

* Initial pub.dev release as **God of Flutter Printer** (`god_of_flutter_printer`).
* Cross-platform thermal printing: Windows, Android, iOS, Web.
* USB (Windows/Android), Bluetooth Classic (Windows/Android), BLE (iOS), network TCP (all).
* Web Print Hub support via `print_agent`.
* Built-in ESC/POS templates (Tamil receipt, KOT, invoice, day close).
* Tamil/Hindi raster fallback for multilingual receipts.
