God of Flutter Printer

Stateless Flutter print worker for thermal and label printers (ESC/POS, TSPL, ZPL).

No database or printer registry inside the package. Your POS app loads printer + order data from your DB and calls one API. The package validates, resolves the connection for the current platform, encodes the payload, and prints.

Architecture

Your DB / API │ ▼ PrintJobBody (JSON) ──► PrintJobResolver ──► platform path │ │ │ ├─ Web → Print Hub → USB / BT / TCP │ └─ Native → direct USB / BT / TCP ▼ PrintJobValidator (sync, instant) ▼ PayloadEncoder (template / text / Tamil raster) ▼ PrintWorker → job result
  • No global printer config in the package.
  • Each job carries its own printer block from your DB.
  • Invalid jobs fail before any network or native I/O.

# pubspec.yaml

  "printerName": "Rugtek Printer",

Validation (fail fast)

Web — Print Hub setup

Browsers cannot access USB or Bluetooth directly. Install Print Hub on the counter PC.

Build (developer)

cd print_agent
.\scripts\package_release.ps1
# Output: print_agent/dist/PrintWorkerHub-win64.zip

Install (shop)

  1. Unzip on the counter PC.
  2. Right-click install_hub.bat → Run as administrator.
  3. Copy LAN URL from desktop shortcut or C:\ProgramData\PrintWorkerHub\hub-url.txt.

Web app JSON

"printer": {
  "printerName": "Rugtek Printer",
  "hubUrl": "http://192.168.1.10:9280"
}

Probe hub

final probe = await PrintWorker.instance.probePrintAgent(
  'http://192.168.1.10:9280',
  discover: true,
);
if (probe.online) print(probe.printers);

Windows native

No Print Hub needed. Uses ip or printerName directly.

USB

  • Install printer driver in Windows.
  • Use exact spooler name in printer.printerName.
  • List: await PrintWorker.instance.listUsbPrinters()

Bluetooth Classic

  • Pair in Settings → Bluetooth.
  • List: await PrintWorker.instance.listBluetoothDevices()
  • Store MAC in printer.address (e.g. 60:6e:41:c8:0e:ad).

Network

Set printer.ip and port (default 9100).

Android native

USB

  • Connect printer via USB OTG.
  • Approve USB permission when prompted.
  • List: await PrintWorker.instance.listUsbPrinters()
  • Use product ID suffix in name, e.g. Rugtek [1234]

Bluetooth Classic

  • Pair first in Android Settings → Bluetooth.
  • List bonded devices: await PrintWorker.instance.listBluetoothDevices()
  • Store MAC in printer.address.

Network

Same as Windows — set printer.ip.

iOS native

iOS does not support USB printing or Bluetooth Classic (SPP). Use BLE thermal printers or network (TCP).

Info.plist

<key>NSBluetoothAlwaysUsageDescription</key>
<string>This app uses Bluetooth to connect to receipt printers.</string>

BLE printer setup

  1. Turn on the BLE thermal printer.
  2. Scan: await PrintWorker.instance.listBluetoothDevices()
  3. Store the device UUID in printer.address (not MAC).
  4. Example UUID: A1B2C3D4-E5F6-7890-ABCD-EF1234567890

Network

Set printer.ip and port — works the same as other platforms.

Run on device

cd example
flutter run -d <ios-device-id>

Discover printers (settings UI)

// Windows / Android USB
final usb = await PrintWorker.instance.listUsbPrinters();

// Native Bluetooth (Classic on Win/Android, BLE on iOS)
final bt = await PrintWorker.instance.listBluetoothDevices();

// Web via hub
final btWeb = await PrintWorker.instance.listBluetoothDevices(
  agentBaseUrl: hubUrl,
);

Production print jobs still use DB JSON — discovery is for admin/settings screens only.

Multi-printer POS

for (final line in order.lines) {
  final printerRow = await db.printer(line.printerId);
  await PrintWorker.instance.printFromMap({
    'type': 'template',
    'templateId': line.templateId,
    'data': line.templateData,
    'printer': printerRow.toJson(),
    'paperWidthMm': printerRow.paperWidth,
  });
}

Kitchen → network IP. Counter → USB. Web cashier → hub. Same schema, different filled fields.

Advanced: PrintRequest API

await PrintWorker.instance.execute(
  PrintRequest(
    connection: PrintConnection.network(host: '192.168.1.50'),
    protocol: PrintProtocol.escPos,
    paperWidthMm: 80,
    mode: PrintMode.text,
    payload: PrintPayload.text('Hello'),
  ),
);

Prefer printFromMap for DB-driven POS apps.
