Print Worker Hub — Shop PC install
==================================

DEVELOPER (once, Windows + Flutter):
  cd print_agent
  .\scripts\package_release.ps1

  Or use the example app: Developer icon -> Generate Print Hub package

SHOP / CLIENT (once per counter PC):
  1. Unzip PrintWorkerHub-win64.zip
  2. Right-click install_hub.bat -> Run as administrator
  3. Copy the LAN URL shown (or open desktop shortcut "Print Worker Hub")
  4. Paste URL into your hosted web app settings

After install:
  - Hub auto-starts on every Windows boot (Scheduled Task: PrintWorkerHub)
  - Runs with highest privileges for USB / Bluetooth
  - URL saved to: C:\ProgramData\PrintWorkerHub\hub-url.txt
  - Web API: http://<this-pc-ip>:9280

Uninstall (Administrator):
  powershell -ExecutionPolicy Bypass -File uninstall_service.ps1
